# HashTable Implementation


Простая реализация хеш‑таблицы на Python с автоматическим увеличением размера и обработкой коллизий.

## Описание

Проект содержит:
* класс `HashTable` с основными операциями (вставка, поиск, удаление, увеличение размера);
* простую хеш‑функцию на основе суммы ASCII‑кодов символов;
* класс `StringHashDict` — словарь строк и их хеш‑значений с использованием хеш‑таблицы.

## Функциональность

### Класс `HashTable`
* **Вставка** (`insert`): добавление пары «ключ‑значение» с обработкой дубликатов.
* **Поиск** (`search`): получение значения по ключу.
* **Удаление** (`delete`): удаление пары по ключу.
* **Увеличение размера** (`resize`): автоматическое удвоение размера таблицы и перераспределение элементов при превышении числа элементов над размером таблицы.
* **Обработка коллизий**: метод цепочек (каждый слот — список пар).

### Функция `string_hash`
Вычисляет хеш‑значение строки как сумму ASCII‑кодов всех символов.

### Класс `StringHashDict`
Словарь, где:
* ключи — строки;
* значения — их хеш‑значения.

Поддерживает добавление, поиск и удаление строк.

## Запуск тестов
python Hash.py
